# create-amusite-admin

Create a Vue 3 + Element Plus admin application using the Amusite business packages.

```bash
pnpm create amusite-admin my-admin --permission --dict --upload
```

Use `--no-request`, `--no-ruoyi`, `--no-permission`, `--no-dict`, or `--no-upload`
to remove optional integrations. Existing non-empty directories are never overwritten
unless `--force` is provided.
