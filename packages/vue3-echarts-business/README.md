# @amusite/vue3-echarts-business

Vue 3 business chart components powered by Apache ECharts 6.

```ts
import { createApp } from 'vue'
import AmusiteCharts from '@amusite/vue3-echarts-business'
import '@amusite/vue3-echarts-business/style.css'

createApp(App).use(AmusiteCharts)
```

The package provides `XChart`, `XChartPanel`, `XTrendChart`, `XMetricCard`, `XRankChart`, and
`useChartRequest`. ECharts, Vue, and Element Plus remain host peer dependencies.
