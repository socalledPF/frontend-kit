# @amusite/vue2-element-business

Vue 2 + Element-UI business components for existing RuoYi-style applications.

Vue 2 is end-of-life upstream. This package receives compatibility and security fixes
only; new applications should use `@amusite/vue3-element-plus-business`.

```ts
import Vue from 'vue'
import AmusiteBusiness from '@amusite/vue2-element-business'
import '@amusite/vue2-element-business/style.css'

Vue.use(AmusiteBusiness)
```
