# @amusite/vue3-element-plus-business

Active Vue 3 + Element Plus business components for RuoYi-style admin applications.

```ts
import { createApp } from 'vue'
import AmusiteBusiness from '@amusite/vue3-element-plus-business'
import '@amusite/vue3-element-plus-business/style.css'

createApp(App).use(AmusiteBusiness)
```
