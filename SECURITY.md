# Security Policy

Report vulnerabilities privately to the repository security contact configured in
the hosting organization. Do not open a public issue containing exploit details,
credentials, tokens, internal registry addresses, or customer data.

Supported releases are the latest Vue 3 package version and the latest compatibility
release of the Vue 2 package. Client-side permission checks do not replace server-side
authorization. Upload accept and size checks are user-experience safeguards; servers
must independently validate content, type, size, malware policy, and authorization.
